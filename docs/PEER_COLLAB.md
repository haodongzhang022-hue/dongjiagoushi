# 同岗位多角色交互机制（Peer Collab）

> 补齐「同一岗位上多个 agent 面对同一个问题」的交互协议——从"分工"到"协同"。
> 引擎：`local-agent/collab/peer.py`

## 背景：分工 ≠ 集群智能

体系已有的协作发生在「任务之间、角色之间」：

- **跨角色接力**：DAG 流水线（产品→总师→经理→开发→评审→测试），上游喂下游；
- **跨任务数据协作**：`collab/engine.py`（loc:// 寻址、ACL、版本、小组提交），共享数据对象；
- **跨小组分形并发**：`fractal.py`，把任务切给不同 agent。

三者本质都是「一个任务 = 一个 agent 单兵，靠切任务/接力/共享数据让多人干**不同的**活」。
协作发生在任务之间、角色之间，而**不是发生在同一岗位上、多个 agent 面对同一个问题时**。

**所以**：分工了，但还没协同。同岗位多 agent 各自为政，产出不会汇聚成更优整体。

## 设计方向（对齐用户确立口径，非全员投票冗余）

用户明确纠偏：**不是投票机制**——同岗位 agent 本身就有能力/专长/触发时机的差异，冗余不是价值。
所以机制的核心是「默认单兵 + 差异化按需补位 + 疑难才专家会诊」：

| 时点 | 动作 | 说明 |
|------|------|------|
| 默认 | **single 单兵** | 一个主战 agent 直做（防无效堆砌，冗余不是价值） |
| 专长缺口 / 卡点 / 加量 | **backup 补位** | 差异 agent 按触发时机补位，不无条件组队 |
| 高风险 / 疑难 / 对错难辨 | **consult 会诊** | 像医学专家会诊，各自从专长角度给结论+留理由，直到收敛 |
| 会诊仍解决不了 | **审核者前置助手 → 人类** | 会诊结束 ≠ 终局，以「功能验证是否通过」为准 |

## 引擎五支柱

### ① cohort（同岗位编队）
同岗位多个 agent 聚成编队，各成员有**差异化专长面**（算法向/工程向/安全向/性能向/数据向…）。
`spawn_cohort(role, lead_agent, ...)` 创建，**gid 稳定寻址**——二次触发取回同一 cohort 不漂移。

### ② 触发时机门控（decide_action）
从「任何时候都投票」改为「按明确信号才差异化增援」：

| 信号 | 动作 |
|------|------|
| 无信号（默认） | single 单兵 |
| skill_gap / stall / scale_up | backup 补位 |
| high_risk / hard / dispute | consult 会诊 |
| 混合 | 会诊信号优先于补位信号 |

### ③ 专家会诊（expert_consult）
疑难才触发；各同岗 agent 从**专长角度**给 `verdict`（可行/存疑/不可行）+ `reason`（留理由）。
收敛判定（`consensus_judge`，初始保守设定，可据收敛表现迭代）：

- 1 人 → 该人意见即共识（单兵，无需集群）；
- 2~3 人 → 无否决（disagree）且 ≤1 弃权（abstain）即共识；
- 4+ 人 → 同意 ≥2/3 且无否决；有否决必须留理由并复评。

**未收敛 ≠ 终局**：走审核者前置助手（L1 内部分支 → L2 外部探索 → L3 交人），以「功能验证是否通过」为准。

### ④ 适配动态扩增 agent（join_cohort）
按负载扩容出来的新 agent 用 `join_cohort(cohort_id, agent_id, specialty)` **加入既有 cohort**，
继承共享上下文并参与同岗位交互（gid 稳定寻址不漂移，差异化分配专长不重复占用）。

### ⑤ 自动分形协同（auto_fractal + team_parallel_execute）
`fractal` 从「串行 for 计划生成器」升级为：
- `auto_fractal`：运行时按任务数决定小组数，并为每个小组建同岗位 cohort；
- `team_parallel_execute`：小组内同岗位多个 agent **真并行**执行 + **互发消息**消费彼此产出，
  不再是串行 for 循环；小组内仍过大可递归再分形，各小组小组长整合后统一向上交付。

## 与既有机制关系

- **跨岗位 DAG**：保留（已成熟），同岗位协作层是它的**正交补全**，不推翻；
- **数据协作 collab/engine**：peer 复用其 gid 寻址与消息管线（`data/admin`）做共享上下文；
- **审核者前置助手**：会诊解决不了 → 接入该链路（L1→L2→L3）→ 人类；
- **哨兵**：对同岗位协作组的收敛做监控，命中停滞/横跳/重复错误按既有协议打断/上报。
