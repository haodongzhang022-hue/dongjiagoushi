# 小组长脑子（Lead Brain · Issue #232）

> 一句话：**小组长不只是拆任务的手，是经理的脑子 + 监察**——经理的分工方案先过小组长
> 诊断缺口补全，经理的每次行动再过一遍看住别犯傻。缺口不齐不许往下派。

## 1. 为什么有这个模块

用户原话（Issue #232）：

> 「小组长我还没见到，需要补充上，经理现在智力严重不足，需要小组长当脑子用给他增强，
> 看着他别犯傻」

翻译成工程问题，经理常见的「犯傻」有四类：

| 症状 | 后果 |
|------|------|
| 方案带窟窿（任务只写"开发"、没写输入输出、没写怎么算完、没指定负责人） | 下游靠猜，做出来的东西不是要的 |
| 跳深度（以为派完就完事） | 下游没接单、没开工、没进度，经理却报"已派发" |
| 重复派发（同一个错误反复试） | 浪费预算、在同一件事上打转 |
| 空转推进（进度零推进还继续往前推）/ 超次返工 / 抢单 | 无人收敛、责任漂移 |

靠"让经理再想想"解决不了——需要一个人**替他补全、盯住他**。这就是小组长的脑子。

## 2. 能力构成

`local-agent/lead_brain/` · `LeadBrainAbility`（**确定性实现，非 LLM 自判**）

| 方法 | 作用 | 输出 |
|------|------|------|
| `diagnose(plan)` | 找方案缺口 | 缺口清单 + 0-100 可执行评分 + `ready` |
| `advise(plan)` | 把窟窿补成可执行 | `fixes`（补字段/拆细/改派/加派/修正方案）+ `escalate`（升总师） |
| `watch(action)` | 看住一次行动 | `verdict: pass｜block｜blocked_escalate` + `reasons` + **`alternatives`** |
| `enhance(plan)` | 一站式（诊断+补全） | 补全后的方案 + `ready` + 评分 |
| `watch_manager_orders(orders)` | 批量看住一串派活 | 逐条判定 + `blocked_count` / `escalate_count` |

### 缺口判据（唯一事实源 `REQUIRED_FIELDS`）

`owner`（谁来做）/ `task`（做什么，不许是"开发""实现"这种空词）/ `input`（拿什么开工）/
`output`（交什么产物）/ `done_when`（怎么算做完，以测试为准），外加 `goal`（北极星）、
`depth`（派活深度须到 L4）、任务编号唯一（gid 不撞车）。

### 犯傻判据（确定性阈值 `DEFAULTS`）

- 跳深度：`depth < 4`（L1 声明/L2 分发/L3 触发都不到「接单后继续工作」）
- 重复派发：同一实体派发 `> 2` 次
- 超次返工：同一任务打回 `> 3` 次（对齐 AGENTS.md 回转协议上限）
- 空转：`progress_delta == 0` 或连续 `3` 轮无推进
- 抢单（同一实体多负责人）/ 无主派发（没指定负责人）
- **二度命中** → `blocked_escalate`，标 blocked 上报总师，不让经理自己扛

拦截必须给**替代动作**，不是只说"不行"——这是和「空喊口号式监管」的区别。

## 3. 接线位置（不是"建了没接上"）

- **全员可用**：`BaseRole` 挂 `lead_brain_ability` + 透传 `enhance_plan()` / `watch_orders()`。
  经理自己也挂得上——**脑子不是小组长私有，谁派活都先过一遍**。
- **小组长角色**：`TeamLeadRole` 暴露 `diagnose/enhance/advise/watch/watch_manager_orders`，
  `capability()` 含 `lead_brain_ability`，输出契约前两条就是脑子职责。
- **编排真实调用**：`orchestrator._lead_brain_enhance()` 在 **`架构·经理` 节点执行后**触发——
  把经理节点的 action 拆成待派活方案 → 小组长诊断 + 补全 + 看住 → 结果写 `report["lead_brain"]`
  与 `card["enhanced_plan"]` 交下游消费。DAG 分支与线性回退分支都接了。
- **云端人设**：`.cnb/settings.yml` 里补上「架构·小组长」（此前只有本地角色，云端 `@` 唤不到）。

## 4. 边界（不越权）

- 补的是**方案的窟窿**，不是**需求的边界**：做什么/为何做仍归总师与经理；
- 小组长判不了的不猜，标 unknown / `escalate` 显式暴露；
- 验收标准必须可客观验证（测试 / lint / 信号灯），不接受「我觉得完成了」。
