# ADR-0005：功能模块解耦开发，独立 PR、base=main，防耦合冲突

- 状态：Accepted
- 决策日期：2026-09
- 相关：AGENTS.md「解耦式功能模块开发」、Issue #29/#30 教训

## 背景
把新功能模块的 base 挂到另一个功能分支/集成分支上，会与该分支耦合，别人一动就冲突
（Issue #29/#30 教训）。

## 决策
每个功能模块**独立成 PR、base 一律为 `main`**（从 main 拉 `auto/<模块>-<随机>` 分支）；
按功能域解耦独立演进，模块间只通过稳定接口/数据契约交互；开 PR 前本地 `merge-tree`
校验无冲突；每 PR 自含测试 + 文档。

## 后果（权衡）
- 好处：模块独立演进、跨项目可复用、冲突前置规避、评审可在 PR 层核验五条（base/域/接口/无冲突/自带测试文档）。
- 代价：需要严守分支纪律、不能图省事挂集成分支。难反转，记 ADR。
