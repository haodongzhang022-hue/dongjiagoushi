1. **PR 真实合并**：`cnb pulls get` 读 `is_merged` / `mergeable_state`，**并且看 base**；

3. `is_merged=True` 但 base 不是 `main` → **不算完成**，判「假合并」入账；
4. 两者缺一 → **不关单**，只记「代码在分支、未进 main」。
